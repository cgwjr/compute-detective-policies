Compute Detective policies

Privacy Notice

Effective 15 October 2026. Operator and contact: Reddit user u/Ok-Worker-2717.

Compute Detective is a free price-research app on Reddit. This notice describes the app's own data handling, not Reddit's or a linked supplier's separate practices.

Information used

  • Reddit supplies a session username, which the app displays. The current app does not ask users for supplier credentials or payment details.
  • The browser's local storage remembers the selected display language. Browser session storage holds workload inputs and a selected quote ID for an on-screen comparison. Users can clear site data in their browser; session storage ordinarily ends with the browser session.
  • The app serves GPU and limited model-token price records from a packaged snapshot or a server-side quote cache. These records are supplier information, not an individual user's workload. Supplier API credentials are held in the operator's Mac mini keychain and are not sent to the user's browser.
  • In the current app code paths, workload inputs are not uploaded to the app server. The app does not maintain an individual user profile or checkout record. This does not describe Reddit's hosting logs or platform telemetry.

Purpose, sharing and retention

Session context and browser-stored selections support language display and price comparison. The app does not sell user personal information and has no payment flow. App-controlled quote caches are replaced as snapshots are updated. Browser language preference remains until cleared, while session selections remain until the session ends or they are cleared.

Reddit may process account and usage information under Reddit's Privacy Policy. External supplier links lead to third-party sites with their own policies. These public policy pages are hosted on GitHub Pages, whose hosting practices are separate from the app.

Requests and updates

For support, access or deletion questions about app-controlled information, message u/Ok-Worker-2717 on Reddit with only the minimum detail needed. Do not send passwords, API keys, one-time codes or other sensitive information. We will explain whether the current app holds identifiable relevant information and handle app-controlled data we can identify and delete. Users can clear browser-held data themselves; Reddit-controlled data is managed through Reddit's own controls. Material changes to this notice will be reflected here with an updated effective date.
